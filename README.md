# MyTube

브라우저 없이 보는 macOS용 유튜브 앱 — 앱이 직접 그리는 영상 목록, 맥 기본 플레이어(4K까지), 듣기 모드, 실시간 한국어 자막, AI 검색·요약

현재 버전: **1.59** · 받기: [릴리즈](https://github.com/lebass98/YouTube/releases) · 사용 가이드: [docs/MyTube-사용가이드.pdf](docs/MyTube-사용가이드.pdf)

## 주요 기능

- **영상 목록**: 홈·새로운 맞춤 동영상·감상한 동영상·최근 업로드·구독·기록·재생목록·나중에 볼·좋아요·내 동영상, 브라우저 같은 탭, 격자/목록형 보기
  - 목록 위 고르기 줄: 기능별(720p+·1080p+·2K+·4K·VR·라이브), 검색이면 날짜·정렬·구분
  - 카드: 화질 표시, 조회수·등록 날짜, 마우스를 올리면 미리 보기, 본 영상·이어 보기 표시
  - 검색: **AI**(말로 설명하면 재미나이가 검색어·필터를 정함) · 기본 · URL
- **재생 창**: 4K까지 가장 좋은 화질, 첫 화면 0.3초 안팎(파일 색인으로 HLS 재생목록을 만들어 재생)
  - 화질 자동 조절, 이어 보기, 15초 이동(← →), 회전(R), 창 크기(1~4), 재생 속도(채널마다 기억)
  - 유튜브 행동 줄: 좋아요·싫어요·댓글·공유·✦ 질문하기/요약·듣기·자막·더보기
  - 댓글·질문하기·다운로드는 플레이어 안에 떠 있는 유리 판으로
- **듣기 모드** (⌘⇧L): 소리만 재생, 작은 듣기 창·큰 화면, 메뉴 막대 미니 플레이어, 미디어 키, 이어폰을 빼면 멈춤
- **쇼츠 모드** (⌘⇧K): 쇼츠만 세로 카드로, 세로 창에서 ↑↓·스크롤로 넘기기
- **한국어 자막**: 플레이어 소리를 받아써서 번역 (일본어·영어·중국어·러시아어·한국어 자동 인식), 두 줄로 아래에서 위로 올라감
- **재생 대기열**·연속 재생, **광고·인트로 건너뛰기**(SponsorBlock), 구독 새 영상 알림
- **다운로드**: 최고 화질 mp4·소리만 m4a, "나중에 볼 동영상" 자동 받기
- **설정**: 유튜브 계정, 업데이트, 색상 테마 7가지(그라데이션 2가지)·화면 모드, 재미나이 계정(유튜브와 따로), 시청 통계, 목록 정리(쇼츠·채널·낱말 숨기기)
- **업데이트**: 앱이 GitHub 릴리즈에서 새 버전을 확인해 알려 주고, 누르면 받아서 설치

## 설치

1. [릴리즈](https://github.com/lebass98/YouTube/releases)에서 `MyTube-<버전>.pkg`를 받아 더블클릭 → `/Applications/MyTube.app`에 설치되고 바로 실행
   - "확인되지 않은 개발자" 경고가 나오면 파일을 오른쪽 클릭 → 열기
2. 필요한 도구 설치 (영상 주소·합치기)
   ```bash
   brew install yt-dlp deno ffmpeg
   ```
3. 앱에서 유튜브 로그인 (처음 켤 때 로그인 창이 뜸, 또는 사이드바 맨 위 "유튜브 로그인")
4. AI 검색·요약을 쓰려면 안티그래비티 CLI(`~/.local/bin/agy`)에 재미나이 구독 계정으로 로그인 (설정 → AI)

이후 새 버전은 앱이 알려 줌 (설정 → 업데이트, 또는 앱 메뉴 → 업데이트 확인…)

## 빌드

요구 사항: macOS 26 이상, Swift 툴체인(Command Line Tools로 충분)

```bash
./build.sh      # 테스트용: ~/Applications/MyTube.app을 만들고 바로 실행
./make_pkg.sh   # 설치 파일 → dist/MyTube-<버전>.pkg (구글 드라이브 "MyTube 배포판" 폴더에도 복사)
```

- 버전은 `Info.plist`의 `CFBundleShortVersionString`
- Command Line Tools만 있으면 SwiftUI `@State`가 빌드되지 않음 → 화면 상태는 `ObservableObject`의 `@Published`에 둠
- 개인용 서명이라 다시 빌드하면 macOS가 권한을 다시 물어볼 수 있음
- 문제 확인용 기록: `~/Library/Logs/MyTube.log` (이 Mac에만, 1MB가 넘으면 오래된 부분 정리)

릴리즈 올리기: 버전을 올리고 `./make_pkg.sh` → GitHub 릴리즈 `v<버전>`에 `dist/MyTube-<버전>.pkg`를 붙여 올리면 앱들이 업데이트를 알아챔

## 단축키

| 키 | 동작 |
|---|---|
| ⌘T / ⌥⌘W / ⌃Tab | 새 탭 / 탭 닫기 / 다음 탭 |
| ⌘R / ⌘L | 새로고침 / 검색 칸 |
| ⌘⇧L / ⌘⇧K | 듣기 모드 / 쇼츠 모드 |
| ⌥⌘Space / ⌥⌘← → | 재생·일시정지 / 15초 이동 (어디서나) |
| ⌥⌘. / ⌥⌘, | 빠르게 / 느리게 |
| ← → / ↑ ↓ | (재생 창) 15초 이동 / (쇼츠) 이전·다음 |
| R / 1~4 | (재생 창) 회전 / 창 크기 |
| ⇧. / ⇧, | (재생 창) 빠르게 / 느리게 |
| Esc | (재생 창) 판 닫기 → 플레이어 끝내기 |
